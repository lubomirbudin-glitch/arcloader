Offload pro Windows — přenosná verze (bez instalace)
====================================================

Spuštění
--------
1. Rozbalte celý ZIP do obyčejné složky (např. Dokumenty\Offload). Nespouštějte ho přímo z archivu.
2. Spusťte Offload.exe.
3. Při prvním spuštění může Windows ukázat modré okno „Systém Windows ochránil váš počítač“
   (aplikace není digitálně podepsaná). Klikněte na „Další informace“ → „Přesto spustit“.
   První start trvá o pár sekund déle (rozbalí se knihovny), další už ne.

Požadavky
---------
- Windows 10 nebo 11, 64bitové. Nic dalšího se instalovat nemusí — .NET, ffmpeg a ffprobe jsou přibalené.
- Kopírování karet, kontrolní součty, report (HTML a PDF), náhledy a proxy fungují hned.
- Proxy na grafické kartě: NVIDIA ověřeno; jinak se kóduje procesorem (pomaleji, ale funguje).

Volitelné doplňky
-----------------
- Blackmagic RAW (.braw): potřebuje knihovnu Blackmagic RAW — stačí nainstalovat zdarma
  „Blackmagic RAW Player“ (blackmagicdesign.com, sekce Support), nebo mít DaVinci Resolve.
  Bez ní se klipy BRAW jen zkopírují a ověří, bez proxy a náhledů.
- RED (.R3D) a ARRIRAW (.ari, .mxf): potřebují nástroje výrobců (REDline, ARRI art-cmd).
  Bez nich se klipy jen zkopírují a ověří.

Co je ve složce
---------------
Offload.exe            aplikace
bin\offload.exe        příkazová řádka (offload --help)
bin\braw-decode.exe    dekodér Blackmagic RAW (knihovnu Blackmagic nepřibaluje)
bin\ffmpeg.exe,
bin\ffprobe.exe        FFmpeg (licence GPL v3, viz licence\ffmpeg)
luts\                  vestavěné LUTy Log → Rec.709 pro proxy
licence\               licence přibalených programů

Nastavení a log
---------------
Nastavení a log aplikace jsou v %APPDATA%\Offload. Smazáním složky Offload se aplikace odinstaluje;
nastavení zůstane v %APPDATA%\Offload, dokud ho nesmažete.

Offload nikdy nezapisuje na zdrojovou kartu.
